## 2026-03-31 - Blazor Password Visibility Toggles & Form Submission Accessibility
**Learning:** In Blazor form components, using `span` elements with `@onclick` handlers for password visibility toggles prevents keyboard navigation (not focusable via Tab) and lacks dynamic screen reader state (static alt text). Furthermore, combining `@onsubmit:preventDefault` on forms with `type="button"` on action buttons prevents users from submitting forms using the Enter key.
**Action:** Always wrap password toggle controls in semantic `<button type="button">` elements with dynamic `aria-label` attributes (`"Ocultar senha"` / `"Mostrar senha"`), mark decorative icons with `aria-hidden="true"`, and use `@onsubmit` with `type="submit"` buttons to ensure full keyboard navigation and screen reader support.
